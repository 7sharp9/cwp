# Framework-spike shared fixture

Status: reference artifact, pinned by TASK-004
Applies to: TASK-004 (Godot spike), TASK-005 (Mibo spike)

Both disposable framework hosts must advance the **same** deterministic
`CommandoWar.Sim` fixture and reproduce the per-tick authoritative state hashes
below. This file is the framework-neutral reference. It is regenerated by:

```text
dotnet run --project src/CommandoWar.Headless -c Release -- fixture
```

The fixture itself is defined once in `src/CommandoWar.Headless/Fixture.fs`
(a framework-neutral project that references only `CommandoWar.Sim`). The
canonical command log is `content/fixtures/spike-fixture.cwlog`.

**Environment (TASK-023):** the per-tick hashes here are pinned on Windows
x64 / .NET SDK `10.0.303`, and `.github/workflows/ci.yml` re-verifies them
there on every push and pull request (via `FixtureTests.fs` and the
`spike-fixture` corpus entry). Other environments are outside the current
per-environment determinism contract (`docs/09_TEST_STRATEGY.md` section 3).

Under the pathfinding-driven movement executor (TASK-015; a straight cardinal
line here, X axis then Y axis since the grid is flat) agent 3 travels 20
cells on X then 11 on Y, reaching `(20, 14)` at **tick 31**, which is also
when `MovementCompleted` is emitted. Ticks 32..40 are a post-arrival rest
state. Total domain events: 34 (1 `CommandAccepted` + 1 `OrderAppraised` +
31 `MovementStepped` + 1 `MovementCompleted`). No random draws occur (no
gameplay phase consumes the stream yet). Every traversed cell costs
`Terrain.BaseMoveCost` (flat terrain), so `Terrain.moveCost` equals the
per-tick progress increment: agent 3 still advances exactly one cell per tick,
and `AgentState.Progress` is 0 at every post-tick checkpoint. This fixture has
**zero enemy deployments**, so `WorldState.TacticalKnowledge` (TASK-026) is
empty at every tick and agent 3's order is `Accepted` at appraisal (TASK-028)
with an empty route exposure. The hashes below moved from the format-3 fixture
because the canonical byte layout gained the `Order` / `Disposition` sections
and one `OrderAppraised` event now fires at tick 1 — agent 3 still reaches
`(20, 14)` at tick 31, tick 40 unchanged (TASK-028 ledger, following the
TASK-018 / TASK-026 precedent).

## Regeneration and verification

- Emit this table: `dotnet run --project src/CommandoWar.Headless -c Release -- fixture`
- Replay the canonical log: `dotnet run --project src/CommandoWar.Headless -c Release -- replay content/fixtures/spike-fixture.cwlog`
- A host's run diverges from the reference: feed the host's command log to
  `cwheadless compare content/fixtures/spike-fixture.cwlog <host-log>` (exit 3
  on any divergence, with the first divergent tick).

If a future `CommandoWar.Sim` change intentionally alters these hashes, bump the
relevant format version, regenerate this file, and note it in the progress
ledger. An unexplained change to this table is a determinism regression.
