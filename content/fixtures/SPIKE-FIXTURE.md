Status: reference artifact, pinned by TASK-004

Both disposable framework hosts must advance the **same** deterministic
`CommandoWar.Sim` fixture and reproduce the per-tick authoritative state hashes
below. This file is the framework-neutral reference. It is regenerated by:


(a framework-neutral project that references only `CommandoWar.Sim`). The

## Regeneration and verification

- Emit this table: `dotnet run --project src/CommandoWar.Headless -c Release -- fixture`
- Replay the canonical log: `dotnet run --project src/CommandoWar.Headless -c Release -- replay content/fixtures/spike-fixture.cwlog`
- A host's run diverges from the reference: feed the host's command log to
  `cwheadless compare content/fixtures/spike-fixture.cwlog <host-log>` (exit 3
  on any divergence, with the first divergent tick).

If a future `CommandoWar.Sim` change intentionally alters these hashes, bump the
relevant format version, regenerate this file, and note it in the progress
ledger. An unexplained change to this table is a determinism regression.
