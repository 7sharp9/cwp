### Why this task, in this shape

`docs/08_ROADMAP_AND_GATES.md` section 6 makes B-045 mandatory before G3.
TASK-020 designated `.cwlog` "a legacy fixture-script format, not the
production replay-command format" and made this the owning follow-up.
Verified against source before drafting:

- `src/CommandoWar.Headless/CommandLogFile.fs`: grammar is `version 1` then
  `<tick> <agentId> move <x> <y>`. No syntax for `Recipients` (a list),
  `Urgency`, `RiskTolerance`, or — after TASK-024 — a distinct `IssuedAtTick`.
  `Version = 1`. Lives in `CommandoWar.Headless`.
- `src/CommandoWar.Sim/Replay.fs`: the *typed* in-memory model
  (`RecordedCommand`, `CommandLog`, `ReplayRecord`) already carries the whole
  `PlayerCommand`. There is no on-disk serialiser for it; `.cwlog` is the only
  on-disk command format. `Replay.FormatVersion` / `CommandLog.Version` = 1.
- `src/CommandoWar.Sim/Canonical.fs`: the `Writer` is fixed-width big-endian
  but **write-only** — no reader, so a binary command format would need its
  own round-trip code.
- `src/CommandoWar.Headless/Corpus.fs`: seven `.cwlog` entries, all
  single-recipient default-envelope `move` commands the legacy format
  expresses fine. `Corpus.DefaultDir = "content/replays"` (repo-relative).
- `src/CommandoWar.Headless/Program.fs`: `Exit` codes `ok=0`, `usage=1`,
  `replayError=2`, `diverged=3`; `cmdCorpus` already exits `3` on a table
  mismatch.
- `docs/04_SIMULATION_SPEC.md` section 16: "Playback rejects incompatible
  versions clearly. It does not guess migrations." G3 evidence wants readable
  decision traces (`docs/08` section 6).
- `docs/notes/2026-09-06-tooling-and-debug-display.md` section 1: the B-049
  shared F# fixture builder deliberately waits for this format so it can emit
  the command stream in memory across the transition; investing in a text
  scenario-plus-command format now would "collide head-on with B-045".

### Design recorded in the task file (recommended resolutions)

- **Decision 1 — a separate new format, not an extended `.cwlog`.** `.cwlog`
  stays frozen at v1 as terse hand-authored fixture-script; the new format is
  machine-written and lossless.
- **Decision 2 — in `CommandoWar.Sim`, no new package.** It is part of the
  determinism contract, not a spike convenience. Hand-rolled like
  `CommandLogFile.parse` / `Canonical.encode`. `System.Text.Json` / YAML /
  binary-serialiser packages forbidden — `src/CommandoWar.Sim` stays
  `FSharp.Core` only.
- **Decision 3 — deterministic line-based text, versioned, typed errors**
  (binary the alternative if Dave prefers compactness). Every envelope field
  representable; room for the later `PlayerIntent` cases without a per-intent
  version bump; `parse >> serialise` and `serialise >> parse` identity.
- **Decision 4 — the corpus is not migrated here.** The seven `.cwlog`
  entries and the spike fixture stay `.cwlog`. The new format is proven by a
  round-trip property and **one committed new-format replay fixture** carrying
  a full envelope (multi-recipient, `Immediate`, `Aggressive`, distinct issue
  tick). Corpus migration + the shared builder are B-049.
- **Decision 5 — version-field blast radius, tabulated.** New file-format
  version literal starts at 1, independent of `CommandLogFile.Version`,
  `CommandLog.Version`, `Replay.FormatVersion`, `Canonical.FormatVersion` (2),
  `ScenarioContent.Version` — all unchanged. No existing hash moves.
- **Decision 6 — a `cwheadless replay <file>` verb** (or a `cmdCorpus`
  extension) that runs and prints the readable decision trace; reuses the
  `Exit` codes. B-050 (divergence visualisation) attaches here later.
- **Decision 7 — no ADR.** Realises `docs/04` section 16's existing
  versioned-replay requirement.
