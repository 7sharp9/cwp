### Design recorded in the task file (recommended resolutions)

- **Two real phases**, Perception (12.3) then Tactical knowledge (12.4), in
  `Phases.order` position, both copying `s.Agents` before writing.
- **Perception output is a per-agent derived cache.** `AgentState.VisibleContacts`
  is a pure function of every agent's `Position`, the immutable `Terrain`, and
  the `SightRange` constant — excluded from `Canonical.encode` exactly like
  `Route`. Moves no hash on its own.
- **Tactical knowledge is a genuine canonical `WorldState.TacticalKnowledge`
  field** (contact id, last-known cell, `LastSeenTick`, decaying confidence).
  It has memory, so under the ADR-0002 amendment it enters the canonical
  image: `Canonical.FormatVersion` **2 -> 3**, a new section in `encode` /
  `topLevelSections` / `firstDifferingSection`, and a **full behaviour-neutral
  hash re-pin** — every committed scenario is enemy-free so the store is empty
  at every checkpoint (the TASK-018 `Progress` situation). Tick counts and
  event counts must be unchanged for all seven entries; a changed count is a
  stop-and-report finding.
- **Implementer latitude:** if the retained decaying store makes the task L,
  the decay/expiry rules may narrow to a focused B-016, landing the
  instant-shared picture with `LastSeenTick` only — but the `WorldState`
  field and the format bump still happen (deferring them only moves the same
  re-pin to the next task).
- **Instant single-squad sharing**, no communication model, no private
  beliefs (B-016 / `docs/05` section 17).
- **One tuning structure** (`SightRange`, confidence bands, `StaleAfter`,
  `ExpireAfter`) as module literals — authoritative, so not on the
  non-authoritative `SimConfig`.
- **Symmetric raw visibility, friendly-squad-only shared knowledge.** A
  hostile squad picture and doctrine reacting to it are B-022.
- **Diagnostics:** new `Overlay.KnownContact`, derived in **both** `frame`
  and `frameOf` (the store is on `WorldState`), rendered in ASCII and SVG,
  a hand-built unit test plus a committed golden for a friendly-observes-
  hostile scenario. First enemy-bearing corpus entry.
- **No ADR** — the ADR-0002 amendment already prescribes the bump procedure.
