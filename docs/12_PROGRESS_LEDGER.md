# Progress and Evidence Ledger

This ledger records what was done and how it was checked. It is split in two.
This file is the **index**: a pinned-facts snapshot and one summary row per
entry. The full record of each entry (owner, source revision, environment,
changes, verification commands, evidence, deviations, documents updated, and
review) lives in its own **detail file** under `docs/ledger/`, named
`YYYY-MM-DD-<ID>-<slug>.md` and keeping its original heading as the title.

A completed task appends a row to the index table below and adds a matching
detail file; if any pinned value changed, the same change refreshes the
"Pinned facts" block. A detail file is never rewritten except to correct a
factual error. An index row is a summary: it states what was delivered and any
caveat that is still live, and defers everything else to its detail file, which
is authoritative if the two ever differ.
